# Gen1 Bag Pockets

Pocketed bag UI for Gen 1 (Items, Balls, Key Items, TMs & HMs) and bag capacity **60**. Left/Right cycles pockets. SELECT reorders within a pocket; the TMs & HMs pocket stays sorted and cannot be reordered.

When [Kanto Reforged](https://github.com/1Jamie/Kanto-Reforged) is also enabled, a **Berries** pocket appears and KR can inject BAG GIVE into the bag menu.

Enable in the F10 mod manager, or in `options.lua`:

```lua
mods = { gen1_bag_pockets = true }
```
